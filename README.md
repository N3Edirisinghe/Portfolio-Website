# 🛡️ Professional Cybersecurity Portfolio

A high-end, responsive portfolio website designed for a Cybersecurity professional. Built with a modern tech stack to showcase projects, skills, and academic achievements with a sleek, hacker-aesthetic interface.

![Portfolio Preview](https://nilupulthisarangaedirisinghe.netlify.app/og-image.png)

## 🚀 Live Demo
Check out the live site here: **[nilupulthisarangaedirisinghe.netlify.app](https://nilupulthisarangaedirisinghe.netlify.app/)**

## 💻 Tech Stack
- **Frontend:** React.js, Vite
- **Animations:** Framer Motion
- **Styling:** Vanilla CSS3 (with Custom Properties & Glassmorphism)
- **Icons:** Lucide React & Custom Brand Logos
- **Contact Integration:** EmailJS
- **Deployment:** Netlify

## ✨ Key Features
- **Interactive Hero Section:** Sleek typewriter effect and a unique "Cybersecurity Scholar" ID badge.
- **Dynamic Projects:** Automatically fetches public repositories from GitHub API.
- **Academic Timeline:** Showcases educational background, certifications, and research interests.
- **Advanced UI/UX:**
  - Custom interactive cursor.
  - Smooth glassmorphism panels.
  - Responsive design for all devices.
  - Hover glow effects and micro-animations.
- **Functional Contact Form:** Integrated validation and real-time email transmission via EmailJS.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/N3Edirisinghe/Portfolio-Website.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure EmailJS (Optional):**
   Update the keys in `src/components/Contact.jsx`:
   ```javascript
   const EMAILJS_SERVICE_ID  = 'YOUR_SERVICE_ID';
   const EMAILJS_TEMPLATE_ID = 'YOUR_TEMPLATE_ID';
   const EMAILJS_PUBLIC_KEY  = 'YOUR_PUBLIC_KEY';
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
